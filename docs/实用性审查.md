# v1.2.0 实用性审查

本轮围绕“导入 → 挑选 → 预览 → 处理 → 失败恢复 → 下次继续使用”检查现有代码，没有扩充新的图像算法。

| v1.1.0 的不足 | v1.2.0 处理方式 |
| --- | --- |
| 只能整文件夹导入、全量处理 | 文件多选、拖放、追加去重、勾选、移除、清空 |
| 失败或取消后只能整批重跑 | 只重试已勾选的失败/取消项，保留成功输出 |
| 混合格式只能统一转换 | 根据文件实际内容保留每张原格式，透明 PNG 仍透明 |
| 失败原因主要依赖悬停提示 | 可滚动、可复制的路径与错误详情 |
| 每次启动都需重新配置 | INI 参数记忆、恢复默认、非法数据回退 |
| 窗口最小高度较大，底部操作不易触达 | 860×520 逻辑像素下内容滚动，主要操作固定底部 |
| 工作中关闭窗口需要等待后再次关闭 | 取消后续任务，保存报告后自动关闭 |

仍保留的边界：

- 文件夹扫描不递归，大量文件的导入/列表填充仍在界面线程；尚未针对上万张图片优化或做长时间压力验收。
- 不支持退出后的任务恢复；失败/取消状态保留在本次打开的列表中，重新启动需重新导入。
- 缩放只按最长边，不包含裁剪、旋转编辑、指定文件大小压缩和批量重命名。
- 仅支持 JPG / PNG / BMP，不含 GIF 动画、HEIC 或 RAW；输出不保证完整保留 EXIF / GPS 元数据。
- 窗口支持小屏滚动，不承诺所有屏幕、字体缩放和辅助技术的兼容；未在个人 Windows 11 新电脑上验收。
- 并发预算是估算缓冲区额度，不是进程内存硬上限；未做断电恢复及无限文件数量测试。

对当前小型工具，后续较有实际价值的是按真实使用量决定是否增加可选子目录扫描、后台导入和应用重启后的任务恢复。其余图像编辑功能可按实际需求增加。
