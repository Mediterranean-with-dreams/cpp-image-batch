# 灰度与压缩使用说明（v1.3.0）

## 最长边与 JPEG 质量

最长边是宽和高中较大的值，单位为像素。例如 4000×3000 的图片设置 1920 后变为 1920×1440，竖图 3000×4000 变为 1440×1920。0 保持原尺寸，小图不放大。该选项只等比例缩小，不裁剪或填充为固定正方形。

JPEG 质量为 1～100，是有损编码参数，不表示保留了百分之多少画质。数值较高通常保留更多细节、文件较大；较低通常文件较小、细节损失较多。重新编码不能恢复原图已丢失的细节，对 PNG / BMP 的保存不使用 JPEG 质量。

## 灰度图片与训练预处理

1. 导入图片，选择“训练灰度 PNG”预设，自动设置为单通道灰度、PNG、保持原尺寸并关闭水印。
2. 如果模型和加载代码需要 RGB 三通道，在“颜色处理”选择“灰度 · RGB 三通道”。
3. 根据需求调整最长边，并选择单独的输出目录，避免把原图和处理图混入同一训练数据集。
4. 点击图片查看灰度预览，确认后处理勾选图片。

单通道 PNG 按 8 位灰度保存；RGB 灰度 PNG 按 RGB 三通道保存，三个颜色分量相等。灰度模式先把透明区域合成为白底，随后应用灰度转换；保留彩色时 PNG 的透明度规则保持不变。JPG / BMP 也可导出灰度外观，模型预处理优先使用 PNG 以避免 JPEG 有损误差。

本工具只负责图片预处理，不负责模型训练、标签、类别划分、数据集分割、张量归一化或固定尺寸裁剪/填充。加载图片时仍需让训练代码按模型要求读取通道数；训练、验证和测试应采用一致的预处理规则。跨文件夹追加图片会汇总到一个输出目录，不自动保留类别子目录结构。

## JPG 压缩

- “照片压缩”预设为 JPG、最长边 1920、质量 85、关闭水印，仍可继续调整。
- JPG 大小上限为 0（不限制）时，直接使用所选 JPEG 质量编码。
- 设置大小上限后，在不超过所选质量的范围内试编码，保存已验证符合上限的结果；不会自动更改转换后的尺寸。
- 1 KiB = 1024 字节，100 KiB = 102400 字节。网页或其他系统若采用不同单位，请按实际字节限制换算。
- 质量 1 的结果仍大于上限时，本项失败且不留下半成品；请降低最长边或提高上限，再重试失败项。

搜索目标是得到经过实际字节校验的达标文件，不保证找到所有质量值中的最高可行值。额外试编码会增加处理时间；取消仍在当前图片完成后生效。

## PNG 无损压缩与结果核对

PNG 的快速、均衡、更小三档均为无损编码，调整档位不会改变解码像素；“更小”可能需要更长时间。Qt 6.8.3 的 PNG 编码器将压缩参数 0～100 映射到内部 0～9，本工具三档采用 0、50、100。参考 [Qt 6.8.3 PNG 实现](https://github.com/qt/qtbase/blob/v6.8.3/src/gui/image/qpnghandler.cpp) 和 [QImageWriter 参数说明](https://doc.qt.io/qt-6.8/qimagewriter.html#setCompression)。

原图已经压缩较好、输出换成更大的格式或添加了内容时，新文件可能比原图更大。本工具不承诺所有图片保存后必然更小。

预览显示原文件大小、预计导出大小和 JPEG 实际采用的质量值，实际导出使用相同转换和编码函数。完成后点击列表行，详情框显示实际前后大小及变化比例，CSV 也记录以下新增列：

| 列 | 含义 |
| --- | --- |
| input_bytes / output_bytes | 输入、已成功保存输出的实际字节数 |
| jpeg_quality_used | 实际 JPEG 质量；-1 表示未使用或未完成 JPEG 编码 |
| color_mode | color 保留彩色、gray_1ch 单通道灰度、gray_rgb RGB 灰度 |

图片仍导出到独立目录，重名追加编号，原图保留。程序记忆灰度、压缩及原有处理参数，可通过“恢复默认参数”重置。
