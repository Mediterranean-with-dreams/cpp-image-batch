## 分发包验收

已通过：将 ZIP 解压到独立目录，清空 Qt/QML 开发路径，进程 PATH 仅保留 Windows 系统目录，启动程序包里的实际 `ImageBatch.exe`，通过其诊断入口驱动同一窗口完成导入、160×100 → 80×50 缩放、JPEG 输出、文字水印和 CSV 报告。

诊断 JSON 记录 `passed: true`、`original_unchanged: true`、`platform: windows`、`qt_version: 6.8.3`。此结果证明当前电脑上无需开发环境路径即可运行该分发包，不等同于已在另一台全新电脑上验证。

打包时 `windeployqt` 提示未找到 DXC/ DXIL；本项目使用 Qt Widgets 的二维界面，实际 Windows 平台启动和批处理验收通过。没有据此声称验证 Direct3D 渲染功能。
